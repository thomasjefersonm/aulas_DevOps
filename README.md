# aulas_DevOps

#O que é DevOps?
DevOps é uma cultura e conjunto de práticas que integram as equipes de desenvolvimento(Dev) e operações de TI(Ops) para entregar software com mais rapidez, qualidade e confiabilidade.

#O que é SRE?
SRE (Engenharia de Confiabilidade de Sites) é uma disciplina criada pelo Google que aplica princípios de engenharia de software para automatizar operações de TI, 
aumentando a confiabilidade e escalabilidade de sistemas. 
SRE equilibram tempo entre resolver incidentes e desenvolver automações para evitar falhas.

# Projeto Frontend

Este projeto consiste no desenvolvimento de uma interface web utilizando React.

O objetivo deste frontend é criar uma aplicação simples que permita a interação do usuário com o sistema, apresentando informações de forma organizada e amigável.

O projeto faz parte da disciplina de DevOps e tem como finalidade demonstrar a utilização de controle de versão com Git, criação de branches e organização do desenvolvimento de software.

Tecnologias utilizadas:

- React
- JavaScript
- HTML
- CSS
- Git e GitHub
